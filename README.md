# Bike Auto Unlock

Public website, support and privacy information for Bike Auto Unlock, an independent iPhone companion for compatible BLACK X RockSolid U-locks.

Website: https://mac8005.github.io/bike-auto-unlock/

Support: support@kleido.style (subject: Bike Auto Unlock).

German, English, French and Italian. This repository contains only public website assets; the app's source, account data and lock credentials are not included. The lock artwork closely follows the compatible RockSolid’s rectangular metal body, thick shackle and underside rotary knob, with logos and decorative X marks omitted. It is a rendering, not the official product photograph. Manrope's license is included in assets/Manrope-OFL.txt.
